# Pencatat Tenggat Tugas Kuliah

Aplikasi Vue 3 + Pinia untuk mencatat tenggat tugas mata kuliah. Data disimpan di localStorage.

## Menjalankan
```
npm install
npm run dev
```

## Fitur
- Tambah, edit, hapus tugas
- Urut otomatis dari tenggat terdekat
- Status belum selesai / selesai / terlambat
- Hitung mundur sisa waktu
- Filter mata kuliah dan status
